# fluff-engine
This is an alpha version of JavaScript game engine.
Here you can [try demo](https://victorsmith241.github.io/fluff-engine/).
# Usage
The engine is in the folder `./js/fluff-engine/`.
It is launched from the `engine.js` file, which contains the initialization function and the main loop.
All the "user" scripts are in the `world/` folder (like a player script), there is also a `world.js` script there for initializing the world.
